# React Date Input

### Installation and usage

```
yarn add
npm install
pnpm install

```

### Example

```
import from "react-date-input';

<ReactDateInput
  onDateChange
  disabled={false} // true or false
  value={""}
  placeholder={""}
  enableTime={true} // true or false
  range={true} // true or false
  size={"md"} // md, sm
>
```
